Email Validator 🔍
➡️ A simple and responsive Email Validator Web App that checks whether the entered email address is valid in format.
Built with HTML, CSS, and JavaScript, and deployed live on Netlify.
The app uses regular expressions (RegEx) to verify if the email follows the correct structure — helping users quickly validate email input in forms or any other use case.

🌐 Live Link: 👉 https://ajmailvalidator.netlify.app

Features:
✅ Simple and clean UI
✅ Instant email validation
✅ Mobile responsive
✅ Built with vanilla JavaScript — no external libraries
✅ Deployed on Netlify for easy access
